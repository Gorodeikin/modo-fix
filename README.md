# Modo Fix

Responsive one-page portfolio project for a fictional home repair and maintenance service in Brindisi Montagna, Italy.

This is a **portfolio project** focused on clean responsive layout, clear service communication, accessible interactions and a working quote request flow.

## Live Demo

https://gorodeikin.github.io/modo-fix/

## Features

- Responsive layout for mobile, tablet and desktop
- Custom Figma-based design implementation
- Mobile navigation
- Service and process sections
- Native accessible FAQ using `<details>` / `<summary>`
- Quote request form with client-side validation
- Multiple image attachments
- Form delivery through FormSubmit
- GitHub Pages deployment via GitHub Actions
- Self-hosted IBM Plex Sans fonts

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Vite
- Git
- GitHub Actions
- GitHub Pages

## Development

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Create a production build:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```
